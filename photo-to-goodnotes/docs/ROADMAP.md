# Roadmap

1. Verify historical experiments and obtain a known-good template archive.
2. Confirm InkSight inference output and implement isolated worker plus schema conversion.
3. Characterize genuine Goodnotes freehand geometry, curve/control data, and unknown fields from controlled imports.
4. Implement lossless archive handling and native pen insertion.
5. Validate import, reopen, move/delete, and partial stroke erase in Goodnotes.
6. Implement reference render, manual actual-render intake, alignment, metrics, and experiment reports.
7. Add candidate search and, only if enough paired data exists, optional learned corrections.

Each milestone should be separately testable. Visual fidelity alone does not establish editability.
