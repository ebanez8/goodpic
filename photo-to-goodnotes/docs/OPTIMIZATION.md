# Optimization boundary

`EncoderParameters` reserves page-point translations, scale, width multiplier, curve/control factors, and an encoding variant. No candidate generator or objective is implemented. SciPy or CMA-ES can later propose parameters against recorded scores. Every experiment records source strokes, configuration, generated archive, supplied actual render, metrics, timestamp, notes, and known Goodnotes version.

Visual optimization measures appearance after Goodnotes renders the document. It cannot prove genuine editable ink. Keep a separate manual functional checklist: import, move, delete, reopen, and partial erase. Use the same Goodnotes version and capture settings across comparisons.
