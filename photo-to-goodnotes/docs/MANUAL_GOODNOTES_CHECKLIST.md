# Goodnotes import checklist

Import fresh files from `generated/phase2_experiments_v2/`, starting with `genuine_clone/result.goodnotes`, then `translated/result.goodnotes`, `scaled/result.goodnotes`, `straight/result.goodnotes`, `letter_a/result.goodnotes`, and `inksight_word/result.goodnotes`. These files were regenerated after the outline fix; v4 contains the same geometry plus diagnostic controls. Each file clears the original template marks, and each reference preview shows the newly inserted strokes. Import as new Goodnotes documents; reopening an earlier imported document does not reload changed archive bytes. Keep the old `generated/phase2_experiments/` files as failed experiment evidence.

If any page is blank, import `generated/phase2_experiments_v4/diagnostic_translated/result.goodnotes`. That file retains the two original template marks and adds the translated pen. If original marks show but translated pen does not, insertion is still rejected. If all marks are missing, investigate page import or archive handling. `diagnostic_letter_a/result.goodnotes` in the same v4 directory provides the same control for the generated A.

If original marks show but added pen does not, import `diagnostic_replace_translated/result.goodnotes`. It replaces the original curved stroke's geometry while keeping its original object ID and wrapper. A visible translated pen there would isolate the problem to creation of a new object; a missing translated pen would point to geometry or compression. `diagnostic_replace_letter_a/result.goodnotes` makes the same check with the first A stroke.

For each import, record the Goodnotes version and whether the document opens. Check the newly added ink's appearance against the matching `reference.png`; pay special attention to the straight line, A corners/crossbar, and word loops. Select one added stroke, move it, delete it, close and reopen the document, then undo or reimport before exporting a PDF. Try a partial eraser across the middle of one added stroke and note whether only that segment disappears. Save a PDF export or screenshot into a separate folder and run `inkbridge compare` with the matching reference; use `--crop x0,y0,x1,y1` if existing template marks or app chrome are visible. Keep the original export alongside the comparison report. These checks determine visual compatibility and editability; local parsing alone does not.
